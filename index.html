Import a ticket pool Proposed

Trac refuses server-side requests, so the plugin cannot fetch tickets itself. Instead it hands you a ready-made query and reads the CSV you download. It then keeps only the tickets a volunteer can actually work, and lists what it dropped and why.

What this demo shows, and why

In the 3 September test chat the team asked for two things in particular. Both are working above, marked Proposed:

  • Difficulty levels, so a ticket's complexity can be matched to a participant's experience. Levels are read from the ticket keywords, and the assignment dropdown sorts a participant's suitable tickets to the top and flags anything they have tested before, so nobody gets a ticket twice.
  • Session history and export (raised by pbearne), so the outcomes can be turned into the recap post. Everything assigned and reported is recorded, exported as CSV, and drafted into a props list and notes with one click.

Ticket import is included because difficulty is read from it. Following the earlier feedback, per-source columns and milestone filtering have been dropped, and a session is treated as either Core or Gutenberg, never both. Everything is additive: with nothing imported and no levels set, the screen behaves exactly as it does today. This is a demonstration, not a pull request; I am happy to build any part the team wants as a focused PR.
