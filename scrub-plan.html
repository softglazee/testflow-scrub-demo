Scrub Plan

Before your first scrub a team lead will normally ask for a written plan: what you intend to run, which tickets you picked, what you dropped and why, and how you will handle the room. This builds that document from the ticket pool you already have, and exports it ready to paste into a Google Doc.

New Google Doc

Copy for Google Docs keeps the headings and tables when you paste. Copy as Markdown is the plain version for GitHub or a handbook page. A plugin cannot create a document in your Drive on its own, so the New Google Doc button just opens an empty one for you to paste into.

Sending it
